# Destiny Islands -- Nintendo DS.  64 x 32 tiles = 1024 x 512 pixels.
#
# Four times the area of the SNES map, which was exactly one 64x32 PPU tilemap
# and could not grow.  This is wider than a single DS 2D background (32x32 of
# these tiles), so the 2D ground renderer streams a window across it; the 3D
# quad ground has no such limit.  See docs/WORLD_SIZES.md.
#
# ~ deep water   - shallow      . sand      , grass     = dock
# # cliff +3     F cliff with the waterfall            C cave floor
# W plunge pool  b bush         T palm      Y nut palm
# R boulder      r rock         L step +1   B bridge +1
# P deck +2      H treehouse +2 M trunk +2  K treetop +3
