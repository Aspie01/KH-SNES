# Destiny Islands -- the play space, 16x16 isometric tiles.
#
# Row index is j, column index is i.  On screen +i runs down-right and +j runs
# down-left, so this square grid renders as a diamond.
#
# Ground level:
#   ~  deep water     (blocked)
#   -  shallow water  (blocked)
#   .  sand           (walkable)
#   ,  grass          (walkable)
#   =  wood dock      (walkable)
#   W  waterfall pool (walkable) -- fill the bottle standing here
#   C  cave floor     (walkable) -- the Secret Place, behind the fall,
#                       a small chamber walled in by the tower
#   T  grass, blocked -- a palm stands here
#   Y  grass, blocked -- a palm with coconuts to knock down
#   R  grass, blocked -- a boulder stands here
#   r  sand,  blocked -- a small rock stands here
#   b  grass, blocked -- a bush
#
# Raised, in eight-pixel steps.  A move is allowed only between tiles whose
# heights differ by at most one, so a deck two steps up can only be reached
# over its step tile:
#   B  wooden bridge  (walkable, +1)
#   L  wooden step    (walkable, +1)
#   P  wooden platform deck (walkable, +2)
#   H  treehouse deck (walkable, +2)
#   M  leaning trunk  (walkable, +2)
#   K  treetop        (walkable, +3) -- the seagull nests up here
#   #  cliff rock     (blocked, +3)
#   F  cliff rock with the waterfall coming down it (blocked, +3)
#
